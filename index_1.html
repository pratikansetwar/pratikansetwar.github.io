Things I've built

Written from scratch with synthetic data — nothing from any employer's systems.

iso8583-decode TypeScript

Decodes an ASCII ISO 8583 card message into a readable field table — MTI, primary and secondary bitmaps, LLVAR/LLLVAR length prefixes, and the data elements that matter when a transaction fails in test. Amounts scale to the currency's minor units; PAN, track 2 and PIN data are masked. Tested on Node 20 and 22 in CI.
