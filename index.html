iso8583-decode TypeScript CI passing

Decodes an ASCII ISO 8583 card message into a readable field table — MTI, primary and secondary bitmaps, LLVAR and LLLVAR length prefixes, and the data elements that matter when a transaction fails in test. Amounts scale to the currency's minor units; PAN, track 2 and PIN data are masked.
